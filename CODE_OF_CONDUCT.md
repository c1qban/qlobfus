# Code of Conduct

This is a research artifact repository. Please keep discussion focused, respectful, and reproducibility-oriented.

## Expected Behavior

- Report issues with enough information to reproduce them.
- Distinguish implementation bugs from expected limitations of empirical semantic testing.
- Respect third-party dataset and tool licenses.
- Avoid posting proprietary source code, private datasets, credentials, or sensitive logs in public issues.

## Scope

This code of conduct applies to public repository interactions, including issues, pull requests, discussions, and artifact-review communication.
